# Bhanu Vamshi — The Other Side of Me

A single-page cinematic portfolio built with HTML, CSS and JavaScript. GSAP + ScrollTrigger are loaded from CDN.

## Run
Open `index.html` in a browser or serve the folder with any static server.

## Content system
All extendable professional/creative content is in `data/content.json`.

Update:
- `profile`
- `professional.roles`
- `professional.skills`
- `professional.certifications`
- `creative.trailerUrl`
- anime / manga / movie placeholders

## Media
Add real personal photography, project screenshots and the AI trailer under `assets/` and update `content.json` / `index.html` paths. The current build intentionally uses original CSS artwork and placeholders rather than inventing or copying anime artwork.

## Deployment
Works as a static site on Vercel, Netlify, GitHub Pages or Firebase Hosting.
